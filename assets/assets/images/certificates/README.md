# Certificate Images

Please add your certificate images to this directory with the following names:

1. `cs_degree.png` - Bachelor's Degree in Computer Science certificate
2. `dep.png` - Digital Egypt Pioneers Program certificate  
3. `flutter_diploma.png` - Flutter Development Diploma certificate

## Recommended Image Specifications:
- Format: PNG, JPG, or JPEG
- Resolution: At least 1920x1080 for best quality
- Aspect ratio: 16:9 or 4:3 (landscape orientation)
- File size: Under 5MB each

## Current Setup:
The app will display a placeholder if certificate images are not found.
Click on any certificate card to view the full certificate image in a dialog.
